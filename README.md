# SpendWise - Budget Tracker

**Student Name:** Eric

## Project Description

SpendWise is a budget management application that helps users manage their monthly budgets, track expenses, calculate total spending, and monitor their remaining balance.

The project uses HTML, CSS, and JavaScript to create a simple and user-friendly budgeting application.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Implemented

### 1. Variables and Data Types
Variables are used to store important application information, including:
- Monthly budget
- Expense names
- Expense amounts
- Total expenses
- Remaining balance

### 2. User Input
The JavaScript `prompt()` function collects information from users, including their monthly budget and expense details.

### 3. Budget Calculations
JavaScript performs calculations to determine:
- Total expenses
- Remaining budget balance
- Whether the user is within or over budget.

### 4. Reusable Functions
The project includes reusable functions:

- `calculateTotalExpenses()` - Calculates all expenses.
- `calculateRemainingBalance()` - Calculates the remaining balance.
- `displaySummary()` - Displays the budget summary.

### 5. Displaying Results
The application uses `console.log()` to display clearly labelled budget information in the browser console.

## Project Files

- `index.html` - Provides the structure of the application.
- `style.css` - Controls the appearance and layout.
- `script.js` - Handles user input, calculations, and application logic.
- `README.md` - Provides project documentation.

## How to Run the Project

1. Open the SpendWise project folder in VS Code.
2. Ensure all four project files are present.
3. Open `index.html` in a web browser.
4. Enter your monthly budget when prompted.
5. Enter the number of expenses.
6. Provide expense names and amounts.
7. Open the browser console using `Ctrl + Shift + J` to view the results.

## Conclusion

SpendWise demonstrates the practical use of JavaScript variables, data types, user input, calculations, loops, and reusable functions to solve a real-world budgeting problem.
